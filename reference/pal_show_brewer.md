# Visualise RColorBrewer Palettes

Display palettes generated by
[`RColorBrewer::brewer.pal()`](https://rdrr.io/pkg/RColorBrewer/man/ColorBrewer.html)
using the same ggplot or gt layout as
[`pal_show()`](https://hui950319.github.io/UtilsR/reference/pal_show.md).

## Usage

``` r
pal_show_brewer(
  palette = NULL,
  n = NULL,
  type = c("all", "qual", "seq", "div"),
  pattern = NULL,
  index = NULL,
  max_colors = 20,
  output = c("gt", "gg", "console")
)
```

## Arguments

- palette:

  Character vector of RColorBrewer palette names. `NULL` shows all
  palettes matching `type` and `pattern`.

- n:

  Number of colours to generate for each palette. `NULL` uses each
  palette's maximum supported size; other values are clamped to the
  supported range of each palette.

- type:

  Brewer palette category: `"all"`, `"qual"`, `"seq"`, or `"div"`.

- pattern:

  Regex pattern used to filter palette names.

- index:

  Integer vector of palette indices to display after filtering.

- max_colors:

  Maximum colours to display per palette. Default 20.

- output:

  Output format: `"gt"` (default) for a gt table, `"gg"` for a ggplot,
  or `"console"` for terminal output.

## Value

A ggplot or gt object, or invisibly the displayed palette list for
console output (all outputs also print).
