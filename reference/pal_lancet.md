# Lancet Colour Palette

A 15-colour palette inspired by *The Lancet* journal style, suitable for
categorical data visualisation.

## Usage

``` r
pal_lancet
```

## Format

A `palette` object (character vector of 15 hex colour codes). Printing
in the console displays coloured swatches automatically.

## See also

Other colour palettes: `pal_bar`, `pal_get()`, `pal_heat`, `pal_list()`,
`pal_other`, `pal_paraSC`, `pal_show()`, `pal_show_brewer()`,
`pal_show_ggsci()`, `pal_show_hcl()`, `pal_show_viridis()`

## Examples

``` r
pal_lancet
#>  [1] "#00468BFF" "#ED0000FF" "#42B540FF" "#0099B4FF" "#925E9FFF" "#FDAF91FF"
#>  [7] "#AD002AFF" "#ADB6B6FF" "#1B1919FF" "#79AF97FF" "#DF8F44FF" "#6A6599FF"
#> [13] "#FCCDE5FF" "#80B1D3FF" "#0000FFFF"
pal_lancet[1:5]
#> [1] "#00468BFF" "#ED0000FF" "#42B540FF" "#0099B4FF" "#925E9FFF"
```
