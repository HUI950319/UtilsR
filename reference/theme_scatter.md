# Scatter / Feature Plot Theme

A clean theme aligned with scMMR's PlotScatter, PlotDynamicFeatures, and
FeaturePlot3. Based on
[`theme_bw()`](https://ggplot2.tidyverse.org/reference/ggtheme.html)
with: title 14pt bold centered, axis title 12pt, axis text 10pt black,
strip text 10pt, legend title 11pt bold, no minor grid lines.

## Usage

``` r
theme_scatter
```
