# Resolve \`theme_use\` input to a ggplot2 theme object

The theme resolver shared by plotting functions in UtilsR and RegR.
Accepts a theme object, a function returning a theme, or a function-name
string. `NULL` uses
[`theme_km`](https://hui950319.github.io/UtilsR/reference/theme_km.md),
with
[`ggplot2::theme_bw()`](https://ggplot2.tidyverse.org/reference/ggtheme.html)
as the fallback. Names are looked up as functions visible to the
immediate caller, then as UtilsR exports, then as ggplot2 exports. Pass
a function or theme object for a local custom theme used through a
plotting wrapper. Errors evaluating a visible binding or calling a theme
function are preserved. Theme functions are called without arguments by
default. Supply settings in a closure or pass them through `...`. Legacy
S3 `plot.background` rectangles are rebuilt with the active ggplot2
constructor so their fill and border remain drawable. Other legacy
elements retain the compatibility requirements of the plotting function.

## Usage

``` r
.resolve_theme(theme_use, ...)
```

## Arguments

- theme_use:

  `NULL`, a single non-missing, non-empty theme name, a function
  returning a theme, or a theme object.

- ...:

  Arguments forwarded to the theme function when one is used. Ignored
  when the specification resolves to a theme object.

## Value

A ggplot2 theme object.
