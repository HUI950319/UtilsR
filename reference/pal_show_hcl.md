# Visualise Base R HCL Palettes

Display palettes generated by
[`grDevices::hcl.colors()`](https://rdrr.io/r/grDevices/palettes.html)
for the palettes listed by
[`grDevices::hcl.pals()`](https://rdrr.io/r/grDevices/palettes.html),
using the same ggplot or gt layout as
[`pal_show()`](https://hui950319.github.io/UtilsR/reference/pal_show.md).

## Usage

``` r
pal_show_hcl(
  palette = NULL,
  n = 8,
  type = c("all", "qualitative", "sequential", "diverging"),
  pattern = NULL,
  index = NULL,
  max_colors = 20,
  output = c("gt", "gg", "console")
)
```

## Arguments

- palette:

  Character vector of HCL palette names. `NULL` shows all palettes
  matching `type` and `pattern`.

- n:

  Number of colours to generate for each palette. Default 8.

- type:

  HCL palette category: `"all"`, `"qualitative"`, `"sequential"`, or
  `"diverging"`.

- pattern:

  Regex pattern used to filter palette names.

- index:

  Integer vector of palette indices to display after filtering.

- max_colors:

  Maximum colours to display per palette. Default 20.

- output:

  Output format: `"gt"` (default) for a gt table, `"gg"` for a ggplot,
  or `"console"` for terminal output.

## Value

A ggplot or gt object, or invisibly the displayed palette list for
console output (all outputs also print).
