# Bar Colour Palette

A 10-colour palette for categorical bar and radial outer-layer
visualisations.

## Usage

``` r
pal_bar
```

## Format

A character vector of 10 hex colour codes.

## Examples

``` r
pal_bar
#>  [1] "#f76502" "#f41237" "#026026" "#2f0d06" "#0372e9" "#f00a0b" "#2e3426"
#>  [8] "#dea34a" "#aa1f19" "#5728a0"
show_color(pal_bar)
#>  #F76502   #F41237   #026026   #2F0D06   #0372E9   #F00A0B   #2E3426   #DEA34A   #AA1F19   #5728A0  
#> c("#f76502", "#f41237", "#026026", "#2f0d06", "#0372e9", "#f00a0b", 
#> "#2e3426", "#dea34a", "#aa1f19", "#5728a0")
```
